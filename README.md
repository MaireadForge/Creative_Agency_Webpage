# Elementum – Creative Agency Landing Page

A high-fidelity, fully responsive single-page React application built from the provided Figma design for the frontend developer internship assignment. 

The project focuses on accurate layout replication, clean component architecture, and fluid responsive design handling complex overlapping UI elements.

## 🛠️ Tech Stack & Architecture
*   **Framework:** React (Vite)
*   **Styling:** Tailwind CSS (with PostCSS)
*   **Icons & Assets:** Custom SVGs / Lucide React

The project is structured with highly reusable, modular components:
*   `Header` / `Navbar` (Responsive mobile menu setup)
*   `Hero` (Dynamic floating avatar cluster layout)
*   `Mission` & `Capabilities` (Asymmetrical split-screen layouts with precision framing)
*   `Services` (Structured interactive rows)
*   `Testimonials` (Centered blockquote layout with floating profile elements)
*   `Footer` / `Newsletter` (Clean grid setup with complete navigation links)

---

## ✨ Key Features & Implementation Highlights
*   **Pixel-Perfect Accuracy:** Meticulous attention to spacing, unique typography weights, pill highlights, and custom border frames matching the Figma specifications.
*   **Asymmetrical & Overlapping UI:** Handled absolute positioning and negative margins cleanly without disrupting the semantic document outline.
*   **Full Responsiveness:** Seamless adaptations from mobile screens up to large high-resolution desktop viewports using mobile-first Tailwind media queries.
*   **Micro-Interactions:** Clean, native hover states on buttons, links, and accordion rows for an interactive user experience.
